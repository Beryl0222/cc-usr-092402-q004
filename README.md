# 碎片文化消费节律保护

本项目用于整理碎片文化消费节律保护领域中的事件名称、交换字段与脱敏样例，方便业务、运营和研发人员在同一套术语下讨论后续服务。资料只包含领域约定，不包含真实个人信息、生产连接或外部账号。

## 目录

- `src/`：事件种类与最小字段校验。
- `src/time_ledger/`：可携带时长账本（见下节）。
- `data/sample.json`：用于核对资料格式的虚构事件。
- `data/sample_report_batch.json`：虚构的跨设备上报批次（电视暂停 → 手机续播 → 离线晚到）。
- `tests/`：保证样例与领域约定保持一致，并验证账本行为。

## 可携带时长账本

`src/time_ledger/ledger.js` 把各终端的上报演进为可开票的时长用量：

- **终端上报**：同步点（`SYNC_POINT`，校正设备时钟漂移）、会话片段（`PLAYBACK_FRAGMENT`）、暂停（`PLAYBACK_PAUSED`，仅留证）、离线下载（`OFFLINE_DOWNLOAD`）；归属规则（`MEMBERSHIP_GRANTED/REVOKED`）与设备绑定（`DEVICE_BOUND`）按生效时间版本化。
- **只扣一次**：同一账户下同一内容按内容位置区间取并集，重叠与断点续播只计一次；每个被去重的区间记录原因（`OVERLAP` / `ALREADY_COUNTED`）与来源片段。
- **当时有效**：归属、设备绑定、内容包规则（日上限、取整）都按片段发生时的有效版本解析；设备时钟按最近同步点校正；账期按片段当地日期归月，跨午夜片段自动切分。
- **封账保护**：未封账的周期晚到数据就地修正；已封账/开票/退款的周期只追加调整（adjustment），原账单行冻结，永不重写。
- **幂等**：事件 ID、片段键、单据 ID 三重去重，同一批上报重放多次不多扣时长、不多退费用。
- **可携带**：`toJSON()` / `TimeLedger.fromJSON()` 整体导出恢复；空账本重放同一事件流得到逐字节一致的状态。
- **可查可诉**：`explainLine()` 从任意账单行展开原始片段、去重原因与调整版本；撤销家庭共享后新汇总立即停止，既有证据仅开放最小范围查验（或显式声明用途）；`fileAppeal()` / `adjudicate()` 支持逐片段申诉并留下裁定（`UPHOLD` / `VOID` / `REASSIGN`）。
